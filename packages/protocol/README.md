# @henira/protocol

契约层：槽位接口（SlotMap 10 槽）+ 引擎 DTO + 封闭词表 + ServerEvent 行词表与账本→行投影器（M3——server 与 sdk 双形态共用的事件→行唯一组装处）。零运行时依赖（[packages.md](../../docs/20-architecture/packages.md) 规则 1），所有插件的公共依赖——工具参数"同形零转换"（D-044）从这里开始。

- 契约出处：[interfaces.md](../../docs/20-architecture/interfaces.md) protocol 段（2026-11-16 定稿）+ server 段（行词表与投影器，2026-11-17 定稿）
- 事件表与注册表：[session.md](../../docs/20-architecture/session.md) §2 / §3
